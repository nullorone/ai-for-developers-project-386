# Слой `features`

Пользовательские сценарии: выбор слота, форма гостя, отмена по management token,
управление доступностью владельца, перенос встречи.

Каталог намеренно пуст: этап 3 создает только каркас и не реализует продуктовые
use cases. Наполняется на этапе 4 (`llm/04-frontend-mocks.md`).

Правила слоя:

- зависит от `entities` и `shared`;
- один каталог — один сценарий вместе с его состояниями loading/empty/error/success;
- запросы к API выполняются только через `shared/api`.
