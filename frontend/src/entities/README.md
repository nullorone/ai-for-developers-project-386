# Слой `entities`

Доменные сущности контракта (`Calendar`, `Slot`, `Booking`, `AvailabilityWindow`):
модели, мапперы UTC → локальное время и презентационные компоненты одной сущности.

Каталог намеренно пуст: на этапе каркаса реальных сущностей нет, а создавать
пустые барrel-модули и обертки над сгенерированными типами «на будущее» запрещено
промптом этапа 3. Наполняется на этапе 4 (`llm/04-frontend-mocks.md`).

Правила слоя:

- зависит только от `shared`;
- не знает о маршрутах и страницах;
- не содержит сценариев (они живут в `features`).
