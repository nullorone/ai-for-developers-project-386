# Сгенерированный код API

Содержимое каталога создается командой `npm run api:generate` из корневого
[`openapi.yaml`](../../../../../openapi.yaml) и **не редактируется вручную**.

- генератор: `openapi-typescript`;
- результат: `schema.d.ts` (типы `paths`, `components`);
- артефакты не коммитятся (`.gitignore`), потому что генерация запускается
  автоматически перед `dev`, `typecheck`, `build` и `test`.

Изменение контракта — только в корневом `openapi.yaml` с обоснованием (ADR 0002).
